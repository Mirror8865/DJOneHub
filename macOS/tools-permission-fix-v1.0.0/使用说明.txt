DJOneHub macOS 权限修复包 v1.0.0

适用范围
1. DJOneHub v1.2.9，macOS 13 或更高版本。
2. 软件打不开通讯录、通话时没有麦克风声音，或后台助手没有运行。

使用方法
1. 先双击“DJOneHub权限检查.command”进行只读检查。
2. 再右键“DJOneHub权限修复.command”，选择“打开”。
3. 在终端输入 YES。
4. macOS 弹出通讯录授权时选择“允许”。
5. 按脚本提示打开麦克风设置，并拨打或接听一次测试电话触发麦克风授权。
6. 在“允许在后台”页面确认 DJOneHub 没有被禁用。

重要说明
- macOS 不允许脚本代替用户点击隐私权限的“允许”。本包会重置旧记录并打开正确页面，但最终开关必须由用户本人确认。
- DJOneHub 不需要完全磁盘访问、辅助功能、屏幕录制、摄像头或输入监控。不要为了“全开权限”降低系统安全性。
- 本包不使用 sudo，不修改 TCC 数据库，不修改模块、SIM、eSIM、USB 或蜂窝网络配置。
- 来电和短信提醒由 DJOneHub 自己绘制，不依赖 macOS“通知”权限。

如果 macOS 阻止脚本
右键文件并选择“打开”，不要直接双击。仍无法打开时，在“系统设置 → 隐私与安全性”底部选择“仍要打开”。
