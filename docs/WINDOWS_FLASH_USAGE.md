# Windows 小白使用说明

本说明只适用于你拥有授权、并确认是 QDC507/DJI 4G 模块的设备。当前 Windows 方案是第三方 WebUSB 候选工具，不是 DJOneHub `v1.0.0` Release 的正式 Windows 软件。它没有 Windows `.exe`，而是在桌面 Chrome 或 Edge 中运行。

## 1. 先判断：你到底需不需要 Windows 首次刷写

| 当前情况 | 应该做什么 |
| --- | --- |
| iPhone/iPad 或 Mac 客户端已经能识别模块，且能查看健康状态 | 不要使用本说明；直接按主项目的正常更新流程使用签名 `.djupdate`。 |
| 模块尚未部署 Agent，只能看到对应 ADB 接口 | 可以继续阅读本说明，但仍须先核对候选包来源。 |
| 设备型号、USB 接口或当前状态无法确认 | 停止操作，不要猜测驱动或反复刷写。 |

## 2. 准备清单

1. Windows 10/11 电脑、最新版 Chrome 或 Edge，以及一根确认可传输数据的 USB 线。
2. 稳定供电；刷写期间不能拔线、断电、休眠或关闭浏览器。
3. 退出 DJOneHub、ADB、串口工具及所有可能占用模块的厂商软件。
4. 如需从源码包启动页面，安装 Node.js `20.19.0` 或更高版本。
5. 不要在 iPhone/iPad 浏览器上尝试这项 WebUSB 首次刷写。

## 3. 获取并核对候选包

只从你信任的上传者或受控存储取得 `DJOneHub-Web-Flash-optimized.zip`。在 PowerShell 中进入文件所在目录后运行：

```powershell
Get-FileHash .\DJOneHub-Web-Flash-optimized.zip -Algorithm SHA256
```

输出必须是：

```text
AF9029DDABE9E617340509DD13C496C40134AA7B85A2D1F38D081014A117D9D0
```

不一致、来源不明、压缩包缺少说明文件时都应停止。不要用本仓库 Release 的 `.djupdate` 替代首次刷写所需的受控载荷。

## 4. 只处理 ADB 接口的驱动

1. 将模块直连电脑，打开“设备管理器”。
2. 确认要处理的是 QDC507 的 **ADB 接口**，其标识应为 Class `FF` / Subclass `42` / Protocol `01`。
3. 仅在确认无误后，把这个单一 ADB 接口绑定到 Microsoft WinUSB。
4. 不要修改同一复合设备的网卡、串口、音频或其他接口驱动。
5. 不能确认接口编号或系统提示要替换整个复合设备时，立即取消并停止操作。

这一步做错会导致 Windows 不再识别模块的其他功能。所谓“一键全设备换驱动”的教程很省事，但也很容易把设备直接搞废，别碰。

## 5. 在本机启动 WebUSB 页面

解压已校验的压缩包，使用 PowerShell 进入其根目录：

```powershell
cd .\DJOneHub-Web-Flash
npm ci
npm start
```

命令会在本机启动 `http://127.0.0.1:4173/` 并打开浏览器。不要直接双击 `index.html`；`file://` 页面无法正确加载模块，也不能使用 WebUSB。

如果页面提示没有可用的签名首次刷写载荷、网络来源不可达或签名校验失败，不要关闭校验、不要改代码绕过校验、也不要把普通更新包强行塞进去。保留错误信息，向提供候选包的人确认受控载荷的来源与版本。

## 6. 连接与执行前检查

1. 在页面中选择“连接 QDC507”或等效操作。
2. 在浏览器弹出的设备选择框中，只选择 VID/PID 为 `2c7c:0125` 的目标模块。
3. 再次确认：模块不在通话中、供电稳定、没有其他程序占用 ADB。
4. 选择页面提供且通过签名验证的目标载荷；不要选择不明固件、测试固件或降级包。
5. 开始后保持等待。USB 配置切换可能让设备短暂断开，先等待页面受控重连，不要立刻拔插或重新点击。

## 7. 完成后的验证

1. 刷写页面明确报告完成后，再正常断开并重新连接模块。
2. 接到 iPhone/iPad 或 Mac，确认 DJOneHub 能读取模块状态与健康信息。
3. 核对 Agent 版本、网络状态和基础连接；确认正常后才考虑短信、通话或后续 `.djupdate` 更新。
4. 如果验证失败，停止重复刷写，保存页面错误、浏览器版本、系统版本和 USB 设备信息后再排障。

## 8. 常见情况

| 现象 | 处理方式 |
| --- | --- |
| 浏览器看不到设备 | 检查数据线、关闭占用程序，并仅检查 ADB 接口的 WinUSB 绑定。 |
| 页面提示 USB 断开 | 保持供电与连接，等待受控重连；不要同时启动 ADB 或串口工具。 |
| 页面提示签名或载荷错误 | 停止操作，重新核对包 SHA-256 与载荷来源。 |
| 刷写后 App 仍不能识别模块 | 不要立即再刷；先保存日志，核对模块型号、USB 枚举与供电。 |
