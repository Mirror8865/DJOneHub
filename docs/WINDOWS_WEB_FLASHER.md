# Windows 电脑刷机页面

## 定位

这是面向 Windows 电脑的**首次刷写候选方案**说明页，适用于用户拥有授权且尚未部署 DJOneHub Agent 的 QDC507/DJI 4G 模块。它与 `module-update-0.3.21.djupdate` 的日常更新不同：后者只能由已经正常运行的 DJOneHub 客户端用于已部署模块。

当前候选方案是第三方提供的 Chrome/Edge WebUSB 刷写器源码包，不是本仓库 `v1.0.0` Release 的正式附件，也不代表已完成 Windows 实机兼容性认证。请勿将其作为量产、维修交付或未经验证设备的刷机工具。

## 已记录的候选包

- 文件名：`DJOneHub-Web-Flash-optimized.zip`
- 类型：静态 WebUSB 页面源码；不是 Windows `.exe` 安装程序
- SHA-256：`af9029ddabe9e617340509dd13c496c40134aa7b85a2d1f38d081014a117d9d0`
- 声称支持：Windows 桌面版 Chrome 或 Edge，通过 WebUSB 连接 QDC507 的 ADB 接口

本仓库只记录该候选包的用途和校验值，不分发它的源码、二进制、密钥或模块首次部署载荷。下载到的同名文件摘要不一致时，立即停止，不要尝试刷写。

首次使用请按 [Windows 小白使用说明](WINDOWS_FLASH_USAGE.md) 操作；不要跳过“确认当前模块是否已部署”的判断。

## 使用前必须确认

1. 你拥有模块及其中数据的操作授权，并确认它确为 QDC507/DJI 4G 模块。
2. 模块未在通话中，供电稳定，并使用确认可传输数据的 USB 线直连 Windows 电脑。
3. 使用最新版桌面 Chrome 或 Edge；iPhone/iPad 浏览器不能执行这类 WebUSB 首次刷写。
4. 只有在设备管理器确认模块的 **ADB 接口** 为 Class `FF` / Subclass `42` / Protocol `01` 时，才可将该单一接口绑定到 Microsoft WinUSB。
5. 不得替换复合设备的网卡、串口、音频或其他接口驱动；无法确认接口时应停止操作。

## 推荐流程

1. 退出可能占用模块的 DJOneHub、ADB、串口工具和厂商软件。
2. 在设备管理器只检查 ADB 接口是否已正确绑定 WinUSB；不要批量更新整个设备的驱动。
3. 核对候选包 SHA-256、模块型号和目标版本，并保存当前设备状态及错误信息。
4. 从受信任 HTTPS 来源打开 WebUSB 页面，按浏览器设备选择框确认 VID/PID 与目标模块一致。
5. 刷写期间不得拔线、断电、关闭浏览器或切换 USB 配置。若 USB 重枚举导致短暂断开，先等待页面的受控重连结果，不要同时启动其他工具。
6. 完成后重新连接模块并验证 DJOneHub 的健康状态；验证失败时停止重复刷写，保留日志后再排障。

## 风险与边界

- 当前 DJOneHub Release 不提供 Windows 首次刷写承诺，也不包含 Windows 刷机 `.exe`。
- 未经验证的 USB 驱动替换、来源不明的刷机包或反复中断刷写，可能导致模块不可用、通信异常或数据丢失。
